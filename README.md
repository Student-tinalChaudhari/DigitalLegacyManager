# Digital Legacy Manager

Digital Legacy Manager is a web-based application developed using Python Flask and SQLite.

It helps users manage their important digital assets, trusted contacts, legacy instructions, and emergency information in one place.

## Features

- User Registration and Login
- Dashboard
- Digital Asset Management
- Trusted Contact Management
- Legacy Instructions Management
- Emergency Information Management
- Add, Edit and Delete Records
- SQLite Database

## Main Modules

### 1. Digital Assets
Users can store and manage information about their important digital assets and accounts.

### 2. Trusted Contacts
Users can add trusted people and store their contact details and permissions.

### 3. Legacy Instructions
Users can create instructions about how their digital information should be managed.

### 4. Emergency Information
Users can store emergency contact information, hospital details and emergency instructions.
